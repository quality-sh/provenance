# Complete document read and local review integration

The catalog operation `read-document` returns the six renderer graph collections
and the complete Thread and Message collections through one pinned projection
transaction. It reuses the store's catch-up and stamp facilities. Separate bulk
lists would need a consumer retry protocol to avoid mixed revisions; this one
transaction supplies the builder's complete input without that protocol or a
second copy of the renderer's placement policy.

The web adapter receives only the canonical generated success type. The host
owns configuration, access, the client connection, selection, refresh, and error
display. The adapter rejects catch-up failure, missing attestations, and missing
or retired roots. No current document remains on screen after a failed refresh.
The generated client also refuses responses above 16 MiB. There is no truncated
success path.

## Retirement evidence

ADR 0004 and the current core/read implementation preserve retired declaration
IDs and relationships while excluding those records from active views. This
operation includes their canonical flags for reference checks. The existing web
placement filters remain in use; a retired root now receives an explicit refusal.
Lifecycle deprecation and approval are separate from retirement. No retirement,
supersession, or review policy is introduced here.

The read-only `bd show provenance-txe --json` attempt failed because the configured
Dolt server had no `provenance` database. No coordinator state was changed. The
implementation uses the available accepted ADR and code evidence; it does not
claim that live bead coordination occurred.

The coordinator later supplied the scope of the open `provenance-txe` ticket:
reader views must identify retired Sources, Requirements, and Rules explicitly.
Active gap, health, coverage, evidence, and Prime views exclude these records.
Indexes, traceability, and impact must not present them as active records.
The current document read preserves all three declaration kinds, their retirement
flags, and their references. The renderer excludes them from active placement and
refuses a retired root. Explicit historical presentation remains open under that
ticket. This change does not resolve that ticket or change lifecycle behavior.
